# Brief — Sistema de Vendas Internas Distac

**Fonte:** solicitação do superior / kickoff no Cursor  
**Data:** 2026-07-23  
**Desenvolvedora:** Prottus  
**Cliente:** Distribuidora Distac

## Contexto de negócio

A Distac distribui material de construção no Estado de Pernambuco. Os clientes são majoritariamente lojas de materiais de construção. O sistema será utilizado pelos **vendedores internos** para registrar e acompanhar vendas.

## Objetivo do sistema

CRUD simples, mas completo, para vendas internas.

## Escopo de dados (somente estas tabelas)

- `pedido`
- `cliente`
- `pedido_item`
- `produto`

## Requisitos explícitos

- Tela de login
- Aplicação escalável e segura
- Sistema simples, mas completo

- Marca (cores / logo)

# Pasta `.cursor/` — HopeMind

Tudo aqui viaja com o repositório: quem clona herda as regras e skills do projeto.

| Caminho | Escopo |
|---------|--------|
| `rules/prottus/*` | Metodologia da empresa — **não editar** |
| `rules/projeto/hopemind.mdc` | Regras do HopeMind (sempre ativas): contexto, stack, match, segurança, UI |
| `skills/hopemind-dev` | Subir/resetar/testar e checklist para mudar questionário ou algoritmo |
| `agents/cursor-cadu.md` | Log de sessões |

## Rules vs Skills

| | **Rules** (`.cursor/rules/`) | **Skills** (`.cursor/skills/`) |
|--|------------------------------|--------------------------------|
| Papel | Normas persistentes / restrições | Como **executar** um fluxo |
| Quando | Sempre ou por glob | Quando a descrição casar com o pedido |
| Exemplo | “Risco nunca entra no score” | “Resetar o banco e rodar os testes” |
